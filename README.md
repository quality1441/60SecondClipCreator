# 60 Second Clip Creator

A local Windows app that cuts long videos into captioned Shorts. You work in the browser at [60scc.vercel.app](https://60scc.vercel.app). Creating happens on your PC.

This repository is the public Windows download. App source is not here.

[Discord](https://qaulity.s.gy/github) · [Patreon](https://www.patreon.com/cw/Qaulity)

## Try it

1. Download `60cc-helper-windows.zip` from [Releases](https://github.com/quality1441/60SecondClipCreator/releases).
2. Unzip it somewhere you will keep.
3. Double-click Install.
4. Use Start 60 Second Clip Creator, then sign in at https://60scc.vercel.app
5. Choose Allow if the browser asks to find apps on this computer, then Connect.

Leave the small Creator window open while you work. Use Stop when you are done.

If something felt unclear, say so. That is what this first drop is for.
